# NFT Preview Card Component - Frontend Mentor Challenge

- This is my solution to the **NFT Preview Card Component** challenge from Frontend Mentor.
- The project is built using **HTML and CSS**, with a focus on Flexbox, positioning, hover effects, image overlays, and responsive-friendly component structure.

## Built With

- HTML5 (Semantic Structure)
- CSS3
- Flexbox (Card layout and content alignment)
- CSS Positioning (`relative` and `absolute`)
- CSS Hover Effects
- CSS Transitions
- Responsive Design

---

## Features

- Centered NFT preview card
- Equilibrium NFT image with rounded corners
- Hoverable image overlay with view icon
- Smooth opacity transition on image hover
- Ethereum price and remaining time section
- Creator profile section with avatar
- Dark-themed card design matching the Frontend Mentor challenge
- Clean component structure using HTML and CSS

---

## What I Learned

- How to create an image overlay using `position: relative` and `position: absolute`
- How to position an element directly over another element using `top`, `left`, `width`, and `height`
- How to use `:hover` to display an element when the user interacts with the image
- How to create smooth hover animations using `transition` and `opacity`
- How to use Flexbox to align icons, text, pricing information, and profile details
- How to structure a small frontend component using semantic HTML
- How parent and child positioning works when using `position: relative` and `position: absolute`

---

## Challenges Faced

- Understanding how to position the image overlay correctly over the NFT image
- Understanding the relationship between `position: relative` on the parent and `position: absolute` on the overlay
- Making the overlay appear only when hovering over the image
- Centering the view icon inside the overlay using Flexbox
- Maintaining consistent spacing and alignment between the different sections of the card
- Matching the colors, sizing, spacing, and overall appearance of the original design
